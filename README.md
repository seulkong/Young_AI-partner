# 🎓 Young-리한 파트너
> **"우리들의 소비를 영(Young)리하게 돕는 AI 파트너"**

Young-AI 파트너는 복합적인 카드 혜택과 통신사 등급을 보유한 대학생들이 편의점에서 놓치기 쉬운 모든 혜택을 챙길 수 있도록 돕는 AI 기반 소비 추천 서비스입니다.

  🔗 [YOUNG리한 파트너 바로가기](https://ai-budget-mate-web.pages.dev/)
  
---

## 📌 프로젝트 개요
대학생이라면 꼭 챙겨야 할 편의점 혜택, 이제는 고민하지 마세요!
- 🙋🏻‍♀️ **소비 스타일 분석**: "나는 어떤 소비 스타일을 가지고 있을까?"
- 🙋🏻‍♂️ **혜택 자동 매칭**: "내 통신사나 카드가 여기서 할인이 되나?"
- 🙋🏻 **스마트 비교**: "CU랑 GS25 중 어디가 더 저렴할까?"

이 모든 고민을 **Young-AI 파트너**가 실시간 데이터와 개인 맞춤형 알고리즘을 통해 해결해 드립니다.

---

## ✨ 주요 기능

### 1️⃣ 개인화 온보딩 및 소비 스타일 매칭
* 사용자의 이름과 소비 성향(헬시플레저, 디저트러버, 브랜드 선호, 트렌드/인기)을 설정하여 맞춤형 큐레이션을 제공합니다.

### 2️⃣ 위치 기반 실시간 행사 상품 조회
* 내 주변 편의점(CU, GS25 등)의 1+1, 2+1 등 월별 행사 상품 데이터를 실시간으로 조회합니다.
* 선호하는 편의점보다 타 브랜드에서 더 큰 혜택이 있을 경우 스마트하게 비교 추천합니다.

### 3️⃣ 하이브리드 할인 계산 엔진
* **통신사 할인**: 멤버십 등급(VIP/Gold/Silver) 및 대학생 전용 혜택(0청년, 유쓰, Y박스 등)을 자동 적용합니다.
* **카드 혜택**: 보유 카드 중 최대 할인/적립/캐시백이 가능한 최적의 카드를 추천합니다.

### 4️⃣ 지능형 AI 챗봇
* 상품 종류(예: 우유) 또는 특정 상품명 입력 시 최적의 할인 조합을 즉시 산출합니다.
* 소비 스타일에 맞는 키워드 추천 및 '근처 편의점 찾기' 지도 연동 기능을 제공합니다.

### 5️⃣ [NEW] Google 생태계 및 Gemini 200% 활용
* **Google OAuth 연동**: `Google Identity Services`를 활용하여 원클릭 소셜 로그인을 구현했습니다.
* **초개인화 시스템 프롬프트(System Instructions)**: 사용자의 소비 성향(자주 가는 편의점, 통신사, 결제 수단)을 조합하여, Google AI Studio에 바로 붙여넣을 수 있는 맞춤형 프롬프트를 원클릭으로 생성합니다.
* **Gemini Vision API 영수증 스캐너**: 편의점 영수증을 업로드하면 Gemini 모델이 텍스트를 인지하여 미처 챙기지 못한 통신사 할인이나 1+1 행사를 팩트폭력과 함께 분석해 줍니다.

## ⚙️ 핵심 로직 

1. **데이터 수집 파이프라인**
   - `crawler` 스크립트가 주기적으로 편의점(GS25, CU)의 프로모션(1+1, 2+1 등) 데이터를 수집하여 JSON 형태로 자동 구축합니다.
2. **할인 가격 역산출 알고리즘**
   - 사용자가 상품을 검색할 때 **기본 행사 할인(1+1 등) -> 통신사 멤버십 할인 -> 신용/체크카드 제휴 할인** 순서로 단계별 중복 할인을 계산합니다.
3. **개인화 및 대학생 특화 추천 시스템**
   - 사전에 입력받은 사용자 성향, 통신사 등급 데이터를 기반으로 타 편의점의 대안 혜택을 제시합니다.
   - 특히 '신한 S20 체크', 'SKT 0청년', 'LG 유쓰' 등 **대학생 전용 혜택을 최우선적으로 감지**하여 추천 멘트에 적극적으로 반영합니다.

## 📁 프로젝트 폴더 구조 

```text
├── frontend/    # 사용자 UI (HTML, CSS, JS) 및 챗봇 인터페이스 화면
│   └── guide/   # 자체 웹 사용 가이드 페이지 및 시각화 다이어그램 문서
├── backend/     # Cloudflare Workers 기반 API 서버 (api_server.py) 및 할인 로직 엔진
├── data/        # 크롤링 결과 JSON, 카드/통신사 제휴 정보 CSV, 사용자 데이터베이스
├── crawler/     # 편의점 행사 상품 자동 수집용 파이썬 크롤러 스크립트
├── scripts/     # 데이터베이스 초기화 및 데이터 삽입용 유틸리티 스크립트
└── docs/        # 챗봇 연동 매뉴얼 등 프로젝트 상세 문서 파일
```

## 🛠 사용한 기술 스택 

### Language & Environment
* **Language**: Python 3.x, HTML/CSS/JavaScript
* **IDE**: Visual Studio Code
* **OS**: macOS
* **Deployment**: Cloudflare Workers (Backend) 

### Data Engineering
* **Web Crawling**: `requests`, `BeautifulSoup` (웹 데이터 수집 및 파싱)
* **Data Processing**: `pandas` (수집된 데이터 정제 및 DB 형태 변환)
* **Database**: `SQLite` (로컬/Cloudflare D1), `PostgreSQL`, `SQLAlchemy` (데이터 최종 저장 및 연동 진행 중)

## 🚀 향후 고도화 계획 (Future Works)

해커톤 이후 상용화 및 서비스 가치를 극대화하기 위해 다음과 같은 고도화를 계획하고 있습니다.

### 1️⃣ 카메라 기반 영수증/바코드 분석 (Vision AI 도입)
- **영수증 스캔 피드백**: 결제 영수증 촬영 시 OCR AI가 결제 내역을 분석하여 "통신사 할인 미적용으로 1,500원 손해" 등 사후 피드백 제공.
- **바코드 스캔 실시간 비교**: 상품 바코드 스캔 시 타 편의점 브랜드의 행사 여부를 실시간으로 비교 안내.

### 2️⃣ '절약 진척도' 대시보드 및 게이미피케이션 (데이터 시각화)
- **개인화 절약 리포트**: 챗봇을 통해 한 달 동안 아낀 금액을 누적하여 마이페이지에 시각화 (예: "이번 달 총 15,400원 절약").
- **리텐션 강화**: 상위 10% 스마트 컨슈머 뱃지 등 게이미피케이션 요소를 도입하여 지속적인 재방문 유도.

### 3️⃣ 실시간 대학생 소비 트렌드 맵 (커뮤니티 데이터 확장)
- **지도 UI 고도화**: 기존 위치 기반 편의점 지도에 '실시간 트렌드 데이터'를 결합.
- 특정 대학가 주변 편의점에서 가장 많이 팔린 행사 상품 Top 3, 가장 많이 검색한 할인 꿀조합 등 트렌드 대시보드 제공.

### 4️⃣ 타임세일 및 마감할인 선제적(Proactive) 알림
- **위치 기반 실시간 알림**: 사용자 위치 반경 내 편의점의 유통기한 임박 마감 할인(픽업 할인) 발생 시 챗봇이 먼저 푸시 알림 제공.

### 💡 데이터 한계 극복 파이프라인
편의점 및 카드 혜택 데이터의 파편화 문제를 해결하기 위해 다음의 파이프라인을 구축할 예정입니다.
1. **크롤링 자동화**: 매월 1일 새벽 공식 홈페이지 프로모션을 자동 수집하는 스케줄링(Batch) 파이프라인 구축.
2. **크라우드소싱 도입**: 사용자가 직접 숨겨진 꿀조합이나 누락된 할인 데이터를 제보하면 혜택을 주는 집단지성 시스템.
3. **타겟팅 최적화**: 초기에는 대학생 사용 빈도가 높은 통신사 3사 및 상위 5개 체크카드 데이터에만 집중하여 추천 정확도 극대화.
